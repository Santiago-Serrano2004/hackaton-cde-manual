# Manual de implementación - Hackatón UNAB Venture Challenge 2026 (reto CDE)

Repositorio de documentación (sin código de aplicación). Lo llena un agente en la nube siguiendo `PROMPT.md` y `CLAUDE.md`.
- `inputs/`: fuentes oficiales y chat del equipo (datos personales ocultos).
- `manual/`: salida del agente. `PROGRESO.md` indica en qué fase va.
- Fuente de verdad del reto: `inputs/01_TyC_y_cronograma_CDE.md`. Un reto anterior ("Mi Tienda en Línea") fue reemplazado y no aplica.

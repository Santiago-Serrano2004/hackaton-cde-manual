**Convenciones comunes (aplican a esta tarea):**

- **Idioma:** código, commits y nombres técnicos en inglés cuando son del framework; **tablas, columnas, rutas de API y textos de interfaz en español** (`03` §6).
- **Backend:** monolito modular en `backend/app/Modules/<Modulo>/` (rutas en `Modules/<Modulo>/routes.php`, *Actions* para casos de uso, *Form Requests* para validar, *API Resources* para JSON, *Policies* para permisos con **denegar por defecto**). - **API:** prefijo `/api/v1`, JSON, `Authorization: Bearer <token>` (Sanctum); paginación `?page=&per_page=` (máximo 50); errores `{ "message": "…", "errors": { "campo": ["…"] } }`; códigos 200/201/204, 401, 403, 404, 409 (conflicto), 422 (validación), 429.
- **Datos:** PostgreSQL; todas las tablas con `id`, `created_at`, `updated_at`, `deleted_at` (borrado lógico) salvo las indicadas; FK `ON DELETE RESTRICT`; `empresa_id` NOT NULL en toda entidad que cuelga de una empresa.

- **Frontend:** `frontend/src/modules/<modulo>/` (rutas en `routes.tsx`), componentes de `frontend/src/components/ui`, estilos con los tokens de `16_sistema_de_diseno.md`, validación con `zod`, datos de servidor con TanStack Query, gráficas con `recharts` cargadas por ruta (`React.lazy`).

- **Commits:** `feat(<modulo>): …` / `fix(...)` / `test:` / `docs:` con `Refs T-xx` en el cuerpo; una tarea = un commit (o una rama `feat/<modulo>-<tarea>`) hacia `develop`; `main` solo por PR con CI verde.

## 4. Contratos

`POST /api/v1/admin/demo/reiniciar` body `{"confirmacion":"REINICIAR"}` → `202 {"estado":"reiniciando"}`; si `APP_DEMO` no es `true` → `404` (la ruta no existe). Solo rol `administrador`. `GET /api/v1/demo/estado` (autenticado) → `{"demo":true,"ultimo_reinicio":"…"}` para mostrar el banner.

## 5. Reglas de negocio

1. El botón y la ruta existen **solo** si `APP_DEMO=true`; con `false` (producción real) no hay ruta, botón ni comando ejecutable.
2. Exige escribir la palabra `REINICIAR` (RNF-12).
3. Ejecuta `migrate:fresh --seed` por cola, deja un respaldo `pg_dump` previo en `storage/app/respaldos/` y registra en `auditoria`.
4. Banner visible «Datos sintéticos · Modo demostración» en todas las pantallas cuando `demo=true`.
5. Durante el reinicio la API responde 503 con `Retry-After`.

## 6. Casos límite

1. Dos reinicios simultáneos: el segundo se rechaza (409).
2. Falla a mitad: restaurar el respaldo previo y avisar.
3. Rol distinto de administrador → 403.
